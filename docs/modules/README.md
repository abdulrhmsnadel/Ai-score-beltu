# Engine guides

Each guide documents what the engine needs, what it checks, and what constitutes a finding. Use these engines only against assets you own or are explicitly authorized to test.

Available commands:

`ssrf` · `csrf` · `api` · `access-control` · `authentication` · `misconfiguration` · `cryptography` · `integrity` · `disclosure` · `cors` · `open-redirect` · `jwt`

Use `beltu engine-info <name>` to see the live requirements from the installed build.
