# Security Policy

## Supported versions

Security fixes are prioritized for the latest development version and the latest tagged release.

## Reporting a vulnerability

Please do **not** open a public issue for a vulnerability in AI-SCORE-BELTU.

For a private repository, use the repository's GitHub **Security** tab and create a private security advisory. If that feature is not enabled, contact the repository owner through a private GitHub channel and include a minimal reproduction.

Do not include real credentials, session cookies, API keys, private keys, customer data, or other secrets in reports.

## Scope and legal use

AI-SCORE-BELTU is intended for systems you own or are explicitly authorized to test. The project enforces an explicit host allowlist for network engines, but users are still responsible for authorization and safe testing.
